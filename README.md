# PulseChat Starter

This ZIP contains the saved PulseChat frontend starter and basic web-app configuration files.

## Important status
- This is a starter/demo, not a complete production social network.
- Some interface actions may save only in the current browser using localStorage.
- Firebase Auth/Firestore calls in `index.html` require the matching Firebase project to be configured and its Authentication, Firestore rules, and billing/quotas checked.
- Voice/video calls, random stranger matching, face/liveness verification, moderation/admin review, and a production Android APK are not fully implemented by this ZIP.
- `pulsechat-logo.png` is referenced by the page but was not present in the saved source; add your logo or remove those image references.

Open `index.html` for a frontend preview. For GitHub Pages, upload the contents of this ZIP to the repository root, not the ZIP file itself.
